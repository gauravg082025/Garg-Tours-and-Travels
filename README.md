# Garg Tours - Rajasthan Travel Studio

A modern React travel website for Rajasthan tours featuring interactive landing pages, custom plane-following cursor animations, destination galleries, and detailed itinerary booking flows.

## Tech Stack
- **React 19**
- **Vite**
- **TanStack Router & TanStack Query**
- **Tailwind CSS v4**
- **Radix UI & Lucide Icons**

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run development server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```
